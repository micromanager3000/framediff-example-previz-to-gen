03 · INVARIANTS

            
The rules that prevent split-brain stacking.

          

          
These constraints turn “one authority” from a UI convention into a testable edit-composition contract.

        


        

          

            AUTHORITY
            
JSON owns order

            
Every visual item has one non-negative integer layer. It is the only persisted stacking value.

          

          

            NORMALIZATION
            
Unique and contiguous

            
After a reorder, occupied ranks normalize to 0…N−1. Simultaneous visual items never tie.

          

          

            PROJECTION
            
Top means front

            
The timeline sorts descending. The renderer paints ascending. Both are pure functions of layer.

          

          

            BOUNDARY
            
Visual order only

            
Audio routing stays separate. It does not receive a fake visual layer merely to appear in the timeline.

          

          

            HTML
            
No authored z-index

            
Edit-item DOM nodes receive a runtime z-index derived from JSON. Conflicting CSS is ignored or diagnosed.

          

          

            LAYOUTS
            
Slots may suggest

            
A reusable layout may offer a default, but the edit binding materializes the final item.layer.

          

          

            HISTORY
            
Reorders are atomic

            
Moving one item may renumber siblings, but the complete reorder commits and undoes as one transaction.

          

          

            RENDERING
            
Preview equals export

            
The same sorted item list feeds both paths, eliminating timeline/preview/render disagreements.

          

        

      


      

        

          

            
04 · ROUGH SCHEMA

            
Spatial and temporal state live together.

          

          
This keeps an edit item inspectable without requiring authors to reverse-engineer geometry or stacking from composition HTML.

        


        

          
{
  "version": 2,
  "canvas": {
    "width": 1280,
    "height": 720,
    "fps": 30
  },
  "items": [
    {
      "id": "hero",
      "from": 0,
      "durationInFrames": 420,
      "layer": 2,
      "content": {
        "type": "nested",
        "composition": "lighthouse-dialogue"
      },
      "layout": {
        "rect": [430, 31, 348, 658],
        "fit": "cover",
        "focalPoint": [0.5, 0.34],
        "cornerRadius": 28,
        "opacity": 1
      }
    }
  ]
}

          

            

              A
              
Content is identifiable.
The item points to an asset, nested comp, text value, or JSON-native shape through a stable ID.

            

            

              B
              
Time and layer are editorial.
from, duration, trim, and layer stay beside the item they position.

            

            

              C
              
Layout is explicit.
Rectangle, fit, focal point, radius, opacity, and later transform fields are editable values—not implied CSS.

            

            

              D
              
HTML remains presentation-capable.
It can render rich content inside the rectangle, but cannot secretly override edit-item geometry or stacking.
